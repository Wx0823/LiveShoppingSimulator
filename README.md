# 拆播间 · Live Shopping Simulator

一款横屏、离线单机的潮玩直播购物模拟器。坐进小桃的虚构直播间，挑选盲盒，让主播拆开，再决定折现还是收藏。

当前版本：**v0.5.0 三国群英版**。使用首版静态小桃布景、桌面自动拆袋、45 位原创国风武将收藏卡、模拟弹幕、离线合成女声、分阶段音效和原创循环器乐。

## 直接玩

在本机项目目录双击 **`启动游戏.cmd`**，或运行：

`dist/v0.5.0/LiveShoppingSimulator-win32-x64/LiveShoppingSimulator.exe`

更新后先关闭正在运行的旧游戏，再启动新版本。桌面端使用单实例保护；旧窗口仍在运行时会优先唤回旧窗口。

打包目录是完整便携版，复制时需要保留整个文件夹，不能只复制 `.exe`。首次本地构建位于 `dist`，体积较大的运行库和打包产物不进入 Git。

## 已有玩法

- 3 个阵营、45 张武将卡：魏·玄武雄图、蜀·青龙义誓、吴·赤虎江潮，每阵营 15 张。
- 左侧大直播画面、底部系列与价格、右侧贯通模拟聊天；每个系列可预览按品质排序的礼物及单件概率。
- 桌面五盒从右端靠近主播处开始拆，向右补位、左端补新盒 → 点击待拆盒选位置（默认最左侧一盒）→ 付款后该盒发光 → 轮到后横向滚动揭晓 → 折现 / 收入背包。
- 模拟观众持续排队代拆：接袋、撕开包装、弹出卡牌、收尾，每轮订单和桌面表现同步。每次可有一笔待处理玩家订单。
- 库存包装、阶梯样品展示、封装用品和拍摄设备组成的近景拆盒工作台。
- 约 5.15 秒开箱揭晓、逐格音效、减速停靠、中央指针和中奖高亮；支持快速模式、跳过和系统减弱动态偏好。
- 背包按固定价格出售；图鉴保留历史发现记录。
- 观看奖励、金币余额、开盒次数、交易足迹。
- 自动保存、未处理开盒恢复、损坏存档备份、桌面单实例保护。
- 原创 118 BPM 循环纯音乐，独立音乐开关 / 音量、音效开关、快速开盒、全屏、模拟弹幕和点赞互动。

全部使用游戏内金币，没有真实付款或现金提现。界面内观众数量和聊天均为虚构氛围内容。

## 玩法数值

初始金币 **1,200**。前台聚焦且没有打开面板时，每观看 30 秒可积攒 60 金币，最多 3 份；点击一次领取全部。后台、关闭游戏和打开面板时不计时。

| 系列 | 价格 | 普通 60% | 稀有 28% | 史诗 10% | 传说 2% |
| --- | ---: | --- | --- | --- | --- |
| 魏·玄武雄图 | 100 | 6 张 / 每张 45 | 5 张 / 每张 100 | 3 张 / 每张 240 | 曹操 / 900 |
| 蜀·青龙义誓 | 260 | 6 张 / 每张 110 | 5 张 / 每张 260 | 3 张 / 每张 650 | 关羽 / 2,000 |
| 吴·赤虎江潮 | 600 | 6 张 / 每张 250 | 5 张 / 每张 600 | 3 张 / 每张 1,500 | 周瑜 / 5,000 |

同品质卡牌均分该档概率：单张普通 10%、稀有 5.6%、史诗 10/3%、传说 2%。预览按品质降序每页五张，可点击查看完整卡面并翻面。历史潮玩藏品与已付款订单继续兼容，往期商品不再出售。
表中物品后的数字为折现金额。每次独立抽取，没有保底。编号仅用于主播拿盒，不改变概率。购买时先写入扣款、盒号、排队位置和固定结果，退出重进后继续排队或处理同一个结果。NPC 代拆仅作表现，不改变玩家经济数据。滚动条仅负责展示，跳过、缩放窗口或切换后台不会改变结果。

快捷键：`空格` 开盒（未聚焦按钮时）、`Esc` 关闭普通面板、`F11` 全屏。

## 开发与构建

环境：Node.js 22 或更新版本、pnpm 11、Windows x64。

```powershell
pnpm install
pnpm start
```

国内网络若无法下载 Electron，可为当前终端设置镜像后重试：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
pnpm rebuild electron
```

```powershell
pnpm test            # 玩法内核测试
pnpm dev             # 浏览器预览 http://127.0.0.1:4173
pnpm test:ui         # 需先启动预览；默认使用已安装的 Microsoft Edge
pnpm test:unboxing   # 需先启动预览；滚动、跳过、中途重载、缩放与减弱动态
pnpm test:live       # 需先启动预览；持续代拆、排队恢复与音乐控制
pnpm test:desktop    # 实际 Electron 启动、存档、单实例测试
pnpm package         # 生成 Windows x64 便携版
```

浏览器预览与桌面版使用独立存档。桌面版存档默认位于 `%APPDATA%/LiveShoppingSimulator/save-v1.json`；重置前的备份保存在同目录。测试使用 `artifacts` 下独立存档，不改动玩家进度。

## 工程结构

```text
desktop/       Electron 主进程、受限 preload 与原子存档
src/game.mjs   纯函数玩法内核、物品配置、存档验证
src/app.mjs    直播交互、开盒流程、背包与图鉴
src/art.mjs    三国卡牌正反面、卡包和往期潮玩渲染
src/reel.mjs   已支付结果的确定性滚动展示
src/live-scene.mjs 桌面自动撕袋、出卡表现
src/music.mjs  原创器乐循环与 WebAudio 播放调度
src/*.css     横屏直播间布局与动画
assets/        原创直播间插画及图像生成记录
tests/         玩法、浏览器与桌面验收
scripts/       本地预览和 Windows 打包
```
