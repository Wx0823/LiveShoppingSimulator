# 拆播间 · Live Shopping Simulator

一款横屏、离线单机的潮玩直播购物模拟器。坐进小桃的虚构直播间，挑选盲盒，让主播拆开，再决定折现还是收藏。

当前版本：**v0.1.0 可玩原型**。使用原创插画、程序绘制的潮玩、模拟弹幕和合成音效；主播目前以插画和字幕表现，尚未加入语音与角色骨骼动画。

## 直接玩

在本机项目目录双击 **`启动游戏.cmd`**，或运行：

`dist/LiveShoppingSimulator-win32-x64/LiveShoppingSimulator.exe`

打包目录是完整便携版，复制时需要保留整个文件夹，不能只复制 `.exe`。首次本地构建位于 `dist`，体积较大的运行库和打包产物不进入 Git。

## 已有玩法

- 3 个系列、12 件藏品：街角漫游、森野来信、星际漫游。
- 购买 → 主播选盒与拆封 → 物品展示 → 折现 / 收入背包。
- 背包按固定价格出售；图鉴保留历史发现记录。
- 观看奖励、金币余额、开盒次数、交易足迹。
- 自动保存、未处理开盒恢复、损坏存档备份、桌面单实例保护。
- 音效开关、快速开盒、全屏、模拟弹幕和点赞互动。

全部使用游戏内金币，没有真实付款或现金提现。界面内观众数量和聊天均为虚构氛围内容。

快捷键：`空格` 开盒（未聚焦按钮时）、`Esc` 关闭普通面板、`F11` 全屏。

## 开发与构建

环境：Node.js 22 或更新版本、pnpm 11、Windows x64。

```powershell
pnpm install
pnpm start
```

国内网络若无法下载 Electron，可为当前终端设置镜像后重试：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
pnpm rebuild electron
```

```powershell
pnpm test            # 玩法内核测试
pnpm dev             # 浏览器预览 http://127.0.0.1:4173
pnpm test:ui         # 需先启动预览；默认使用已安装的 Microsoft Edge
pnpm test:desktop    # 实际 Electron 启动、存档、单实例测试
pnpm package         # 生成 Windows x64 便携版
```

浏览器预览与桌面版使用独立存档。桌面版存档默认位于 `%APPDATA%/LiveShoppingSimulator/save-v1.json`；重置前的备份保存在同目录。测试使用 `artifacts` 下独立存档，不改动玩家进度。

## 工程结构

```text
desktop/       Electron 主进程、受限 preload 与原子存档
src/game.mjs   纯函数玩法内核、物品配置、存档验证
src/app.mjs    直播交互、开盒流程、背包与图鉴
src/art.mjs    原创可缩放潮玩图形
src/*.css     横屏直播间布局与动画
assets/        原创直播间插画及图像生成记录
tests/         玩法、浏览器与桌面验收
scripts/       本地预览和 Windows 打包
```
